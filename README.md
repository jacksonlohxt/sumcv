# SumCV

SumCV is a portfolio website project.

## Purpose

This project will become a focused personal portfolio for presenting selected work, experience, and contact information through a clear, responsive web experience.

## MVP scope

- Portfolio landing page
- Selected work and project case studies
- About and experience section
- Contact call to action
- Responsive and accessible presentation

## Status

MVP scaffold. Product direction, visual system, and implementation details are still being defined.

## Development

Project setup and development instructions will be added as the website implementation begins.
